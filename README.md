## Interactive Features Summary
1. **FPS Setup:** Created and configured First Person Unreal Engine project.

2. **3 Spinning Objects:** Implemented `BP_SpinningObject` using `RotatingMovement` with visible surface patterns and distinct scale/rotation speeds.

3. **Keypress Print String:** Wired Level Blueprint to output a custom text message to screen upon pressing `F`.

4. **Fire Hazard:** Built `BP_FireHazard` to spawn/activate a fire particle system when player overlaps the hazard bound.

5. **Toggleable Light Switch:** Built `BP_LightSwitch` using `OverlapAllDynamic` collision to toggle point light visibility on/off upon stepping onto the pad.
